## 🏁 Getting Started

1. **Clone the repo**

    ```bash
    git clone https://github.com/yourusername/your-repo.git
    cd your-repo
    ```

2. **Install dependencies**

    ```bash
    npm install
    ```

3. **Run the development server**

    ```bash
    npm run dev
    ```

    The app will run at [http://localhost:3000](http://localhost:3000).
